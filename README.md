# Product_03 — 실내 러닝 기록 앱 (Apple Watch + iPhone)

Apple Watch와 iPhone을 연동해 실내 러닝을 측정하고 기록하는 앱 프로젝트입니다.

## 현재 단계

**기술 검증(Technical Validation) 단계**입니다. Xcode 프로젝트와 애플리케이션 코드는 아직 작성하지 않았으며,
문서와 폴더 구조만 준비된 상태입니다. 워치에서 실내 달리기를 측정·기록하고 HealthKit에 저장하는 것이
기술적으로 가능한지 먼저 확인하는 것이 목표입니다.

## 최종 제품과의 관계

이 프로젝트의 최종 목표는 워치 연동 자체가 아니라, 사용자의 러닝 데이터를 콘텐츠 진행으로 변환하는
엔진을 만드는 것입니다. 다만 현재 단계에서는 콘텐츠 엔진을 구현하지 않고, 러닝 측정·기록이 기술적으로
안정적인지를 먼저 검증합니다. 자세한 내용은 [PRODUCT.md](./PRODUCT.md)를 참고하세요.

## 폴더 구조 (예정)

Xcode 프로젝트가 아직 생성되지 않았으므로, 아래 폴더는 향후 프로젝트를 구성할 위치를 미리 표시해 둔
빈 자리표시자입니다.

```
App/        iOS(iPhone) 앱 타겟이 들어갈 예정 위치 (미생성)
WatchApp/   watchOS 앱 타겟이 들어갈 예정 위치 (미생성)
Shared/     양쪽에서 공유할 코드/모델이 들어갈 예정 위치 (미생성)
```

실제 폴더 구성은 Xcode 프로젝트 생성 시점의 결정(단일 프로젝트 vs 워크스페이스, 앱 확장 방식 등)에
따라 달라질 수 있습니다.
